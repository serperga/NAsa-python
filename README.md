# 🚀 NASA APOD Explorer con ChatGPT y LlamaIndex

Este proyecto conecta la **API de Astronomy Picture of the Day (APOD) de la NASA** con **OpenAI (ChatGPT)** y **LlamaIndex**.  
Permite descargar imágenes astronómicas, indexarlas en un motor semántico y hacer consultas en **lenguaje natural** como:

- “Muéstrame imágenes relacionadas con eclipses solares”
- “Dime fotos que hablen de la Luna”
- “Quiero ver entradas sobre nebulosas”

---

## 📌 Requisitos

- Python 3.10 o superior
- Claves de API:
  - [NASA API Key](https://api.nasa.gov/) (puedes usar `DEMO_KEY` para pruebas)
  - [OpenAI API Key](https://platform.openai.com/)
